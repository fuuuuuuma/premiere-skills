# テロップチャンネルパターン（テンプレート）

`/srt` / `/srt-fast` の改行工程が参照するチャンネル固有の固有名詞辞書・スタイル分析の**原典**
（実行時に読まれる蒸留版は `references/srt_runtime_rules.md`）。

このリポジトリは配布用のため、実データは含めていない。自分のチャンネルで運用する場合は、
Premiere Pro で完成させた動画（手直し済みテロップ）と `/srt` / `/srt-fast` の出力を見比べ、
差分から得た知見をこのファイルに追記していく。定量的な設定値（目標文字数など）は
`config/channel_profile.md` に、固有名詞の言い間違い辞書は `config/corrections.local.json` に持つ。

## 学習元

分析対象にした動画のリスト（内部管理用のタイトルやメモ）をここに書く。

## チャンネル表記ルール

ユーザー指示で確定した表記ルール（例: 半角スペースの有無、略称の統一表記など）を表にする。

| 表記 | 備考 |
|---|---|
| （例）ブランド名はスペースなし | 自チャンネルでの確定表記があればここに追記 |

## 固有名詞辞書（確度順）

Whisper が誤変換しやすい固有名詞を、出現頻度の確からしさで分類して蓄積する。
実際の自動置換は `config/corrections.local.json` に反映すること（このファイルはあくまで分析の原典）。

### 確度A（複数本で繰り返し出現・ほぼ確実）

（分析後に追記）

### 確度B（1本で複数回出現）

（分析後に追記）

### 確度C（1回出現・今後も出る可能性あり）

（分析後に追記）

## テロップスタイルガイド

初期値は `references/srt_runtime_rules.md` セクション4の目標値（平均14字前後・25字超1%未満等）を
使う。自チャンネルで完成版と比較して傾向が異なることが分かったら、ここに実測値を追記して
`config/channel_profile.md` の目標値を更新する。

## prproj トラック構造

テロップの種類（通常/キーワード/CTA等）は動画ごとに V トラック番号が変わるため、
内容で判別する必要がある。自チャンネルの構成が分かったらここに記録する。

| 用途 | 判別方法 |
|------|----------|
| メイン映像 | クリップ数最多 |
| 通常テロップ | 会話字幕、最多テキスト |
| キーワード | 短い強調フレーズ |
| CTA | 同一テキスト繰り返し |

## タイムラインオフセット

WAV（元音声）と prproj（編集済みタイムライン）の間にオフセットが生じることがある
（イントロ・B-roll・グラフィック挿入等が原因）。動画ごとに実測してここに記録する。

## 編集スタイル

完成版テロップは Whisper 文字起こしの一部（要約・編集版）になるのが通常。
自チャンネルでの「文字数比率」「タイムラインカバー率」等が分かったら記録する。
