## テロップ分割タイミング（学習中・3本分析）

### 観察パターン（No.769より）
- **スペース = 発話ポーズ**: テロップ内の半角スペースは編集者が意図的に入れた間（例: "払えません こんなの"、"結構 それが話題になりましたもんね"、"うん かっこいいですね"）
- **リアクション独立**: 相手のリアクション「なるほど」「そうですね」「すごい」は独立したテロップになりやすい
- **助詞で分割**: 「〜なんですよ」「〜じゃないですか」等で完結する発話は1テロップ
- **続きの予感で前止め**: 「制限がかかると」「今となっては」のように次の発言を引き出す形で前止めになることがある
- **発話末尾カット**: 長い発話をトリミング（例: Whisper「Grok全然使えますそうなんですよ」→ prproj「Grok全然使えますね」+「そうなんですよ」（別テロップ））
- **複数SRTセグメントをまとめる**: 連続する短いセグメントを1テロップにまとめることがある

### 分割単位の傾向（No.769 通常テロップ）
- 平均文字数: 約11字（No.767/768の13.9字よりやや短め）※3本目なので要継続観察
- 会話テロップは発話の1〜2フレーズ単位で分割

## 通常テロップ vs 強調テロップの使い分け（学習中）

### No.769で観察した強調テロップ候補
短い（5-8字）、インパクトある単語・リアクション:
- 「どうなんだい」「これはすごい」「みんな大好き」「今となっては」「制限がかかると」
- 「お願いします」「出てきました」「分かんないとか」「なんとそろそろ」
- 「生成っ!」「0クレジット」「v8が出てくる...！？」「1枚は黒髪...」（視覚的インパクト系）

### No.769で観察した数値強調テロップ（強調テロップに多い）
- 「1,500円です」「72%Off」「40%Off」「0クレジット」「0クレジットの使用w」
- 価格・割引率・数値単体は強調テロップとして独立させることが多い

### 通常テロップとの使い分け基準（暫定）
- **通常テロップ**: 会話の流れを追う9-15字のフレーズ
- **強調テロップ（キーワード）**: ポイントを強調する5-8字の短いフレーズ。通常テロップのギャップ区間に配置
- **CTA**: 同一テキストの繰り返し（No.769では動画タイトルを74回使用）

### 未解決・今後の学習ポイント
- どの発話フレーズを強調テロップにするかの選択基準（感情的盛り上がり？情報量？）
- 同じフレーズがSRTと異なる文字列でテロップ化されるケース（要継続観察）

### 分割点の違い（V4 vs 私の SRT で 264箇所の差分）

**LLM 分割時の最重要教訓**: 「繋げられるから繋げる」ではなく、**節・主語・話題の切替点で積極的に分ける**。

#### 典型パターン（V4 で観察）
- `レベルになってきており人間が` → `レベルになってきており` + 次テロップで `話す必要は〜`
  - → **「〜おり」で終止させ、「人間が」を次テロップに送る**（私は前に繋げていた）
- `人間と区別できなくなるのかというのを徹底的に` → `〜のを` + `徹底的に検証して〜`
  - → **副詞句「徹底的に」は次テロップの先頭**（私は前に繋げていた）
- `今回なんですけどもより皆さんが〜` → `今回なんですけども` + `より皆さんが〜`
  - → **「ですけども」で分離**、フィラー的接続は単独テロップ化
- `今の検証企画をより深く理解できるように` + `LINE登録者限定で`
  - → **話題転換（説明→CTA）は必ず切る**

### フィラー処理の精密化（V4 で観測）
- **削除強化（私の SRT にも残っていた）**:
  - `ですよ` 文中: 21 → 13（final で 8 件削除）
  - `さん` 不要呼称: 12 → 9（final で 3 件削除）
  - `ですけど` 末尾: 35 → 32（3 件削除）
- **保持を強化（私は削りすぎた）**:
  - `こう`（副詞・強調）: final で 5 回使用 → 私は 0 回（削りすぎ）
  - `ちょっと`: final で 1 回使用 → 私は 0 回（削りすぎ）
  - → **「こう」「ちょっと」は意味を持つケースがあるので全削除禁止**
- **文末フィラーの区別**:
  - 「〜ですね」「〜ますね」: 基本残す（共感マーカー）
  - 「〜ですよ」「〜ですよね」: 強調マーカー、残す方向だが冗長なら削除可
