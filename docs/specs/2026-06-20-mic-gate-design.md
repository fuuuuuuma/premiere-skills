# 設計書: 話者マイク自動ゲート（`/mic-gate` 仮称）

- 日付: 2026-06-20
- ステータス: 設計承認済み（実装前）
- 著者: Claude Code（[NAME]との対話設計）
- 関連: `/cut`（`scripts/silence_cut.py`）の分割機構を流用

---

## 1. 背景・目的

二人の演者がそれぞれピンマイクを持ち、A1・A2 トラックに片方ずつ録音された素材がある。
2本は重ねて同期済み（ズレは前提としない）。

やりたいこと: **片方の演者が喋っている区間は、もう片方のマイクを「無効」にする。**
Premiere の「クリップを有効/無効」トグルを、人手でなく XML 加工で自動付与する。

結論（フィージビリティ）: **XML 往復だけで実現可能。プラグイン不要。**
根拠は `scripts/silence_cut.py:229-230` が既に各 clipitem の `<enabled>` を読み書き対象にしており、
Premiere の有効/無効は FCP7 XML（xmeml）の `<enabled>TRUE/FALSE</enabled>` に 1:1 対応するため。
音量解析も `/cut` の RMS エンベロープ機構（`detect_silence_envelope`）をそのまま流用できる。

## 2. 用語

- **被り / bleed / クロストーク**: 演者Aの声が演者Bのマイクにも小さく入る現象。被りは本人の声より必ず小さい。
- **発話判定**: あるフレームで、そのマイクの持ち主が「実際に喋っている」か否かの真偽。
- **ドミナンス**: 2本のマイクの相対音量関係。被り由来かどうかの切り分けに使う。
- **ゲート**: トラックを発話の有無で ON/OFF（有効/無効）に切り替えること。

## 3. スコープ

### やること
- A1・A2（既定。`--mic-tracks` で変更可）の2本のマイクトラックを対象に、
  発話区間で分割し、各断片に `<enabled>` を付与する。
- 被りレベルを素材から自動実測（キャリブレーション）し、被りを発話と誤判定しない。
- 非破壊。Premiere 側でいつでも有効に戻せる（クリップを消さず enabled を切るだけ）。

### やらないこと（YAGNI / 今回は意図的に除外）
- 音声の実加工・ゲイン処理・クロスフェード（= 別案B。今回は採用しない）。
- パネル/プラグイン（UXP/CEP）（= 別案C。採用しない）。
- 3本以上のマイク（設計は2本前提。N本対応は将来拡張）。
- 映像トラック・BGM/SE 等その他の音声トラックへの変更（一切触らない）。

## 4. 全体像

`/cut` と同形の **スタンドアロン Python スクリプト**。
Premiere「ファイル＞書き出し＞Final Cut Pro XML」→ スクリプト → 「ファイル＞読み込み」で戻す。

```
入力XML ─▶ [1]解析 ─▶ [2]自動キャリブ ─▶ [3]発話判定 ─▶ [4]平滑化 ─▶ [5]分割+enable ─▶ [6]出力XML
```

## 5. 処理フロー詳細

### [1] XML 解析（`/cut` 流用）
- `build_file_id_map` / `resolve_file_path` でトラック別の音声ファイルパスを取得。
- 各 clipitem の `in/out/start/end`、`offset = in_frame - tl_start` を個別保持。
- タイムベース（timebase/ntsc）と ticks/frame を確定。フレーム↔秒換算は**宣言 timebase 基準**
  （`/cut` の累積ドリフト対策と同じ。実 fps は配置換算に使わない）。

### [2] 自動キャリブレーション（被りレベル実測 / 方式c）
- A1・A2 の全長にわたり RMS エンベロープを算出し dB 化（窓 ~20–50ms、ホップで連続値）。
- 絶対 floor（既定 −50dB）で「アクティブなフレーム」を判定。
- **A ソロ区間の検出**: A がアクティブ かつ A_dB − B_dB が大きく上回る（既定 ≥ 12dB）フレームの連続を、
  一定長（既定 ≥ 0.5s）以上のときソロと認定。B ソロも対称に。
- ソロ区間内で相手マイクの相対レベルを実測:
  - `BLEED_AB = median(A_dB − B_dB)`（A がソロのとき B に出る被り減衰量, dB）
  - `BLEED_BA = median(B_dB − A_dB)`（B ソロのとき A に出る被り減衰量, dB）
- **フォールバック**: 信頼できるソロ区間が取れないトラックがあれば、
  `--calib-range start,end` で基準区間を手指定。それも無ければ保守的な固定マージンで継続し、警告を出す。

### [3] 発話判定（相対ドミナンス / 方式a）
各フレーム t について、A・B を**独立に**判定（= 採用した「両方ONを許す」挙動）:

```
A_speaking(t) = A_dB(t) > floor  AND  A_dB(t) > (B_dB(t) − BLEED_BA) + margin
B_speaking(t) = B_dB(t) > floor  AND  B_dB(t) > (A_dB(t) − BLEED_AB) + margin
```

- 直感: 「A のマイクの音が、B からの被りで説明できる大きさ（B_dB − BLEED_BA）を
  margin 以上超えていれば、A は本当に喋っている」。被りは定義上それ未満なので自動的に弾かれる。
- `margin`（既定 4dB）は安全マージン。
- 両方が各々の被り予測を超えれば両方 speaking（同時発話＝両方ON）。

#### ゲート式（最終的な有効/無効の導出）
発話フラグから各トラックの enabled を次式で導く。**「自分が喋っている」だけでなく
「相手が喋っていない」も ON 条件にする**のがポイント:

```
enabled_A(t) = A_speaking(t)  OR  NOT B_speaking(t)
enabled_B(t) = B_speaking(t)  OR  NOT A_speaking(t)
```

この1式で、採用した挙動がすべて自動的に満たされる:
- A ソロ（A発話・B無）→ B は OFF、A は ON（= 相手を消す本来の目的）。
- 同時発話 → 両方 ON。
- **両者静か（無音）→ 両方 ON 維持**（誰も喋らないので相手を消す理由がない）。

### [4] 平滑化（チャタリング防止）
平滑化は **enabled_A / enabled_B のタイムライン**に対して掛ける（speaking ではなく最終ゲートを整える）。
- **ヒステリシス**: enabled の OFF 化（相手が喋り出して自分が無効になる側）は、
  確定まで off-hold（既定 0.25s）の継続を要求し、語尾を切らない。ON 化は即時（食い気味の入りを拾う）。
- **最小区間長**: 0.3s 未満の ON 区間・OFF 区間は作らない（隣と統合）。
- **境界寄せ**: 切替境界を低エネルギー側へ数フレーム寄せ＋パディング。
  ハードカット（フェード不可）のポップ回避。OFF は元々静音区間で立つので境界は谷に落ちる。
- 出力はトラックごとの enabled ON/OFF 区間リスト（タイムライン位置・元のまま）。

### [5] 区間分割＋enable 設定（`/cut` 分割機構の応用）
- 対象トラック（A1/A2）ごとに、[4] の enabled 区間境界がクリップ内に来る点で clipitem を分割。
- 各サブクリップの `in/out/start/end` を再計算（**start/end は元のタイムライン位置のまま。
  `/cut` と違い削除して詰めない**）。`pproTicksIn/Out`、file 参照（同一 fileID は初回のみ詳細、
  以降は空参照）、新 ID 採番も `/cut` と同じ。
- 各サブクリップに `<enabled>TRUE/FALSE</enabled>` を付与（[4] の enabled 値をそのまま）。
- **`<link>` の中立化**: A1/A2 を独立点で分割すると映像との連結が 1:1 で崩れるため、
  v1 では分割した音声クリップの `<link>` を中立化し独立クリップ扱いにする（安全側）。
- 映像トラック・その他音声トラックは deep copy で素通し（無変更）。

### [6] XML 出力
- `/cut` と同じ DOCTYPE/宣言処理で書き出し。
- 出力先: premiere-skills の `output/`（`output/mic-gate/` を新設）。
  worktree ルートに出さない（`/cut` と同方針、`realpath` で canonical を導出）。
- ファイル名: `<入力ファイル名>_ゲート済み.xml`（最終確定は実装時）。

## 6. 既定パラメータ

| 項目 | 既定 | CLI |
|---|---|---|
| 対象マイクトラック | A1,A2 | `--mic-tracks` |
| 絶対 floor | −50 dB | `--floor` |
| ドミナンス margin | 4 dB | `--margin` |
| ソロ認定の優越量 | 12 dB | `--solo-dominance` |
| ソロ最小長 | 0.5 s | `--solo-min` |
| 最小区間長 | 0.3 s | `--min-seg` |
| OFF ホールド | 0.25 s | `--off-hold` |
| 境界パディング | 数フレーム | `--padding` |
| キャリブ方式 | auto（手動フォールバック） | `--calib auto\|manual` `--calib-range` |
| 無音時の扱い | 両方 ON 維持 | （固定方針） |
| 出力先 | `output/mic-gate/` | `--output-dir` |

## 7. `/cut` との流用・相違

- **流用**: トラック別オフセット保持、RMS エンベロープ解析、クリップ分割（in/out/start/end・
  pproTicks・file 参照・新 ID 採番・宣言 timebase 基準換算）。
- **相違**: ①削除して詰めない（位置不変）②`<enabled>` を能動的に書く
  ③A1/A2 を独立点で分割 ④`<link>` 中立化 ⑤被りキャリブレーションという新工程。

## 8. エッジケース・リスク

- 信頼できるソロ区間が無い → 手動 `--calib-range` フォールバック＋警告。
- マイクがステレオクリップ → 解析時にモノダウンミックス。
- トラックに複数クリップ／オフセット差 → `/cut` 同様に個別処理。
- 極端に小声の演者 → floor を取りこぼす可能性。`--floor` で調整可能にする。
- 同時発話が多い掛け合い → 両方 ON が頻発するが、それは仕様（採用した挙動）どおり。

## 9. 実機検証ポイント（完了報告の前ゲート / 机上で「動く」と言わない）

1. **往復テスト**: 2トラックの小素材を書き出し→スクリプト→読み込みし、
   OFF 区間が実際に**無効クリップ（グレーアウト＝出力でミュート）**になることを確認。
2. **`<enabled>FALSE` の反映**: 手で1クリップ無効にした書き出しと、スクリプト出力の
   enabled 表現が一致することを確認（順逆両方向）。
3. **`<link>` 中立化**: シーケンスが壊れない・選択連動の不具合が出ないことを確認。
4. **境界ポップ**: 数か所の切替点を試聴。
